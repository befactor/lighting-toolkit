# أدوات محمد للإنارة (Lighting Toolkit)

أدوات ويب لشركة تصميم وبيع الإنارة الداخلية والخارجية والمسابح والديكورية:

1. **حاسبة توفير الطاقة** (`energy-calculator.html`) — مقارنة أي وحدتين إنارة، مبلغ التوفير، وفترة استرداد رأس المال، مع تحذير لو التوفير كان على حساب شدة الإضاءة (لومن).
2. **مصمم مشهد الإضاءة** (`scene-configurator.html`) — رفع صورة موقع ووضع كشافات مقترحة عليها من كتالوج المنتجات، مع تصدير صورة جاهزة للزبون فيها قائمة الأسعار.
3. **أفكار إضاءة بالذكاء الاصطناعي** (`ai-room-advisor.html`) — رفع صورة غرفة/مكان والحصول على اقتراحات إضاءة من كتالوج المنتجات مباشرة (يحتاج ضبط مفتاح API، انظر تحت).

## طريقة التشغيل

الصفحتين الأولى والثانية تشتغلوا **بدون أي تثبيت أو إنترنت** — بس افتح `index.html` بأي متصفح.

صفحة "أفكار AI" تحتاج نشر على Vercel (أو أي منصة تدعم Serverless Functions) لأنها بتتصل بسيرفر خلفي — ما بتشتغل بفتح الملف مباشرة بالمتصفح محلياً.

## ضبط الذكاء الاصطناعي (مطلوب لصفحة "أفكار AI" فقط)

1. افتح مشروعك على [vercel.com](https://vercel.com) → **Settings** → **Environment Variables**.
2. ضيف متغير جديد:
   - **Name**: `ANTHROPIC_API_KEY`
   - **Value**: مفتاحك من [console.anthropic.com](https://console.anthropic.com)
3. احفظ، وبعدها اعمل **Redeploy** للمشروع (من تبويب Deployments → ⋯ → Redeploy) حتى يتعرف على المتغير الجديد.

المفتاح ما بينكتب أبداً بالكود ولا يترفع على GitHub — بضل محفوظ بإعدادات Vercel فقط.

## هيكلة الملفات

```
lighting-toolkit/
├── index.html                  الصفحة الرئيسية
├── energy-calculator.html       حاسبة توفير الطاقة
├── scene-configurator.html      مصمم مشهد الإضاءة
├── ai-room-advisor.html         أفكار إضاءة بالذكاء الاصطناعي
├── style.css                    الستايل المشترك لكل الصفحات
├── api/
│   └── suggest-lighting.js      سيرفرلس فنكشن يتصل بـ Claude API
├── data/
│   └── products.js              كتالوج المنتجات — عدّله بمنتجاتك الحقيقية
└── js/
    ├── energy-calculator.js
    ├── scene-configurator.js
    └── ai-room-advisor.js
```

## أهم شي تعدّله أول شي

افتح `data/products.js` وحط منتجاتك الحقيقية (الاسم، الفئة، القدرة بالواط، درجة حرارة اللون، السعر). هاي القائمة يستخدمها مصمم المشهد مباشرة.

## أفكار للتطوير لاحقاً

- ربط الأدوات بقاعدة بيانات حقيقية بدل ملف JS ثابت (عشان الأسعار تتحدث من مكان واحد).
- إضافة تصدير عرض سعر PDF منسق بلوغو الشركة.
- إضافة صفحة كتالوج منتجات كاملة للزبائن.
- دعم اختيار درجة حرارة اللون بصرياً (فكرة رقم 13 من النقاش).
- ربط اقتراحات "أفكار AI" مباشرة بمصمم المشهد (وضع الكشافات المقترحة تلقائياً على الصورة).
