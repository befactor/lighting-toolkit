# أدوات محمد للإنارة (Lighting Toolkit)

أداتين ويب بسيطتين لشركة تصميم وبيع الإنارة الداخلية والخارجية والمسابح والديكورية:

1. **حاسبة توفير الطاقة** (`energy-calculator.html`) — مقارنة تقليدي مقابل LED، مبلغ التوفير، وفترة استرداد رأس المال.
2. **مصمم مشهد الإضاءة** (`scene-configurator.html`) — رفع صورة موقع ووضع كشافات مقترحة عليها من كتالوج المنتجات.

## طريقة التشغيل

المشروع **بدون أي تثبيت أو Node أو إنترنت** — بس افتح `index.html` بأي متصفح (كروم مثلاً) وابلش.

لو حاب تشغله عن طريق سيرفر محلي بسيط (اختياري، بيحل أي مشكلة نادرة بمتصفحات معينة):

```bash
# لو عندك بايثون مثبت
python3 -m http.server 8080
# بعدها افتح http://localhost:8080
```

## هيكلة الملفات

```
lighting-toolkit/
├── index.html                 الصفحة الرئيسية
├── energy-calculator.html      حاسبة توفير الطاقة
├── scene-configurator.html     مصمم مشهد الإضاءة
├── style.css                   الستايل المشترك لكل الصفحات
├── data/
│   └── products.js             كتالوج المنتجات — عدّله بمنتجاتك الحقيقية
└── js/
    ├── energy-calculator.js
    └── scene-configurator.js
```

## أهم شي تعدّله أول شي

افتح `data/products.js` وحط منتجاتك الحقيقية (الاسم، الفئة، القدرة بالواط، درجة حرارة اللون، السعر). هاي القائمة يستخدمها مصمم المشهد مباشرة.

## أفكار للتطوير لاحقاً

- ربط الأداتين بقاعدة بيانات حقيقية بدل ملف JS ثابت (عشان الأسعار تتحدث من مكان واحد).
- إضافة تصدير عرض سعر PDF منسق بلوغو الشركة.
- إضافة صفحة كتالوج منتجات كاملة للزبائن.
- دعم اختيار درجة حرارة اللون بصرياً (فكرة رقم 13 من النقاش).

## الترخيص

مشروع خاص لصالح محمد — استخدام داخلي فقط.
